  transition: opacity 700ms var(--ease), transform 700ms var(--ease), filter 700ms var(--ease); }
.node > :nth-child(2){transition-delay:90ms} .node > :nth-child(3){transition-delay:180ms} .node > :nth-child(4){transition-delay:270ms}
.node.lit > * { opacity:1; transform:none; filter:none; }   /* label → title → text → fact */
.node.lit::before { background:var(--accent); box-shadow:0 0 12px rgba(233,254,133,.5); }
/* JS: one timeline (2400 ms, ease-in-out) drives the line; every frame, a node gets .lit the moment
   the line reaches its dot, so dot and text start together, one step after another. */

/* Tablet + mobile (below 1024) */
.pin { height: calc(100vh + var(--travel)); }        /* --travel = track width - viewport width */
.pin-inner { position:sticky; top:0; height:100vh; overflow:hidden; }
.track { display:flex; gap:24px; transform: translateX(calc(var(--p) * -1 * var(--travel))); }
/* JS: target = clamp((scrollY - pin.top) / travel, 0, 1); each frame current += (target - current) * 0.14
   (smooth follow, no jumps); move the track by current; the line fills up to a focus point at
   55% of the screen width and a step lights when its dot reaches that point;
   each line of a step (label, title, text, fact) fades in, rises 12 px and un-blurs (6 px → 0)
   continuously with the scroll, one after another, so nothing pops; unlit steps sit at 35% opacity. Scrolling up runs it backwards. */

      Pricing
Same cryptography on every tier
A proof issued on the free tier verifies exactly like one issued on Enterprise, permanently. Volume, seats and history length are what change.

    

      
Permanent means permanent
Cancel your account and every signature you’ve already issued still verifies — verification doesn’t consult us. Your hosted searchable history and your ability to issue new signatures end with the subscription.

      
Signed records and verifications are separate meters
A signed record is one signature we issue. A private verification checks a signature that isn’t public and requires authentication. Public verification is unmetered on every tier, because it happens on the reader’s machine.
